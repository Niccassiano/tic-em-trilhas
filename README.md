## 📌 Sobre o Repositório

Este repositório reúne todos os exercícios e atividades práticas desenvolvidos ao longo das **4 trilhas** do programa. O foco é a programação em **linguagem C** com ênfase em **algoritmos iterativos** — estruturas de repetição, lógica de programação e resolução de problemas com modelo iterativo.

## ▶️ Como Compilar e Executar

Com o GCC instalado, para compilar qualquer exercício:

```bash
gcc Trilha-01/exercicio.c -o exercicio
./exercicio
```

Ou use a extensão **C/C++** no VS Code com o terminal integrado.
